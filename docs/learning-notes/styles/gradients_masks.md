## LinearGradient і MaskedView

### LinearGradient — що це

Пряма лінія через елемент, уздовж якої колір плавно переходить з одного в інший.

**`colors`** — масив кольорів, мінімум два. Перший — початок лінії, останній — кінець, усе між ними — проміжні точки.

**`locations`** — числа від `0` (початок лінії) до `1` (кінець), по одному числу на кожен колір з `colors`, обов'язково по зростанню:

```tsx
colors={['rgba(0,0,0,0.5)', 'rgba(0,0,0,0.45)', 'transparent']}
locations={[0, 0.7, 1]}
```

Без `locations` кольори розставляються рівномірно самі (для двох кольорів — `[0, 1]`, для трьох — `[0, 0.5, 1]`).

**`start`/`end`** — не пікселі, а частки від `0` до `1` відносно розмірів самого елемента. `{x:0, y:0}` — лівий верхній кут, `{x:1, y:1}` — правий нижній, незалежно від реального розміру в px. Напрямок лінії — стрілка від `start` до `end`.

За замовчуванням (якщо не вказувати): `start = {x: 0.5, y: 0}`, `end = {x: 0.5, y: 1}` — тобто згори вниз.

```tsx
start={{ x: 0, y: 0 }}  end={{ x: 1, y: 0 }}   // зліва направо
start={{ x: 0, y: 0 }}  end={{ x: 1, y: 1 }}   // діагональ
```

### MaskedView — що це

Показує реальний контент (`children`) не весь одразу, а рівно настільки, наскільки дозволяє окремий елемент-трафарет (`maskElement`) — піксель за пікселем.

```tsx
<MaskedView
  maskElement={<LinearGradient colors={['white', 'transparent']} style={StyleSheet.absoluteFill} />}
>
  <BlurView .../>          {/* children — реальний, видимий контент */}
</MaskedView>
```

**Головне правило: важлива лише прозорість (alpha) трафарету, не колір.** `maskElement` сам ніколи не малюється на екрані — глядач його не бачить як картинку. Значення має тільки те, наскільки він прозорий у кожній точці:
- непрозоро (alpha = 1, будь-який колір — білий, чорний, червоний, байдуже) → children показані на 100%
- `transparent` (alpha = 0) → children невидимі повністю
- напівпрозоро (alpha = 0.5) → children показані на 50%

Колір `white` у прикладі вище взятий довільно — з тим самим успіхом міг бути `'red'`, результат ідентичний.

## Поширені помилки

### 1. Видима смуга-злам на переході (різна швидкість зміни кольору)

**Симптом:** у градієнта з трьома й більше кольорами на позначці, де стоїть проміжна точка (`locations`), видно ледь помітну, але чітку лінію — хоча жодного різкого стрибка кольору в коді немає.

**Причина:** людське око дуже чутливе не лише до самого кольору, а й до **швидкості** його зміни. Якщо швидкість переходу різна до й після проміжної точки — око сприймає цю зміну швидкості як лінію, навіть коли колір міняється плавно.

**Конкретний приклад — погано:**
```tsx
colors={['rgba(0,0,0,0.65)', 'rgba(0,0,0,0.4)', 'transparent']}
locations={[0, 0.6, 1]}
```
Порахуй швидкість на кожній ділянці (зміна прозорості / довжина ділянки):
- Ділянка 1 (0% → 60%): `0.65 → 0.4`, зміна `0.25` за `60%` довжини → швидкість `≈ 0.42`
- Ділянка 2 (60% → 100%): `0.4 → 0`, зміна `0.4` за лише `40%` довжини → швидкість `= 1.0`

Швидкість на другій ділянці більш ніж удвічі вища за першу — саме на позначці `60%` й буде видно "злам".

**Той самий приклад — виправлено, швидкість однакова:**
```tsx
colors={['rgba(0,0,0,0.6)', 'rgba(0,0,0,0.3)', 'transparent']}
locations={[0, 0.5, 1]}
```
- Ділянка 1 (0% → 50%): `0.6 → 0.3`, зміна `0.3` за `50%` → швидкість `= 0.6`
- Ділянка 2 (50% → 100%): `0.3 → 0`, зміна `0.3` за `50%` → швидкість `= 0.6`

Однакова швидкість на обох ділянках — злому немає.

**Найпростіший спосіб уникнути взагалі:** якщо проміжна точка не потрібна для конкретного ефекту — лишити лише два кольори, без `locations`. З двома кольорами злому швидкості фізично не може бути, ділянка одна, пряма.

**Як перевірити себе на око, не тільки рахунком:** для кожної сусідньої пари точок обчислити `(різниця значень) / (різниця locations)` — якщо числа на різних ділянках помітно відрізняються (не в межах десь ±20%), очікуй видимий злам.

### 2. Плутанина "колір = показати/сховати" в масці

Здається інтуїтивним, ніби "білий = показати, чорний = сховати" (як шари в Photoshop). У `MaskedView` це **не так** — важлива тільки прозорість, колір ролі не грає. `maskElement={<LinearGradient colors={['black', 'transparent']} .../>}` спрацює так само, як `colors={['white', 'transparent']}`.
