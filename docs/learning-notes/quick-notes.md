## Images

### Розміри картинок: web vs React Native
- **Web:** `<img>` без розмірів до завантаження має висоту 0, після завантаження бере розмір із файлу → контент стрибає. `width`/`height` в атрибутах задають пропорцію заздалегідь, браузер резервує місце.
- **RN:** картинка з мережі ніколи не бере розмір із файлу. Без явних розмірів вона 0×0 і невидима. Розміри задаються завжди → стрибків немає.
- Пропорцію файлу в RN враховувати не треба: задаєш розмір рамки, `contentFit` вписує картинку.
- Щоб рамка мала потрібну пропорцію, задавай тільки ширину + `aspectRatio: 2 / 3`, висоту RN обчислить сам.
