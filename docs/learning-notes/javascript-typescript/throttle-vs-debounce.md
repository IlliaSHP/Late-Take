## Throttle vs debounce

Обидва — техніки обмеження, як часто виконується функція у відповідь на подію, що стріляє часто (скрол, набір тексту). Різна логіка обмеження.

### Throttle — виконуй регулярно, поки триває дія

`scrollEventThrottle={16}` — не частіше одного разу на 16мс (≈60 разів/сек), скільки б скрол не стріляв частіше.

Часова шкала (throttle 16мс, скрол безперервно 3 секунди):
```
0мс ──── 16мс ──── 32мс ──── 48мс ──── ... ──── 3000мс (кінець скролу)
 ▲          ▲          ▲          ▲                    ▲
виконав   виконав   виконав   виконав          (весь час
                                                 виконував
                                                 регулярно)
```
Функція виконується весь час, поки триває дія — рівномірно, з фіксованим інтервалом.

### Debounce — почекай, поки дія затихне, виконай один раз

Приклад — пошук під час набору тексту (debounce 500мс):
```
Ти друкуєш: р-е-а-к-т (кожна літера скидає таймер на 500мс наново)
р....е....а....к....т [перестав друкувати]....500мс тиші....ВИКОНАВ пошук
```
Поки продовжуєш друкувати — функція взагалі не виконується, кожна нова літера скидає таймер заново. Спрацьовує рівно один раз, тільки коли дія на якийсь час завмерла.

### Різниця в двох словах

Throttle — "роби регулярно, поки триває дія". Debounce — "почекай, поки дія закінчиться, і зроби один раз у кінці".

Для скролу потрібен throttle — анімація має оновлюватись весь час, поки скролиш, а не лише один раз після того, як відпустив палець.
