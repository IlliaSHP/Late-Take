# Нотатки з розробки

Це не документація проєкту — це мої особисті нотатки: речі, які я вивчав, пригадував чи розбирав глибше під час роботи над цим репозиторієм. Не все, з чим я стикався, а конкретно те, що виявилось не очевидним і варте того, щоб зафіксувати — щоб не пояснювати собі це з нуля за кілька місяців, і щоб сам код лишався чистим, без розлогих коментарів "про запас".
